Spesifikasi Skill VPR Queue Mode v2 Claude AI

Verified Paper Research: Queue Mode

Protokol riset akademik bebas halusinasi berbasis antrian Git. Claude mencari kandidat paper, automasi GitHub Actions memvalidasi berkas PDF secara ketat, dan hasil diverifikasi melalui fetch commit SHA langsung tanpa token API di chat.

Repositori: github.com/maryam0508/vpr-claude-skill
Versi: SKILL.md v2.0.0
Zero API Token di Chat

Tidak perlu menempelkan Personal Access Token GitHub ke jendela obrolan. Repositori publik dipicu secara aman hanya melalui Git push berkas antrian.

Git Push Automation

Perubahan pada queue/requests.json otomatis memicu runner GitHub Actions untuk mengunduh, menguji 4 syarat validitas, dan mengekstrak dokumen ke Markdown.

SHA-Based Raw Fetch

Claude membaca berkas data menggunakan URL berbasis commit SHA terbaru. Menghindari delay cache statis CDN raw.githubusercontent dan menjamin akurasi revisi.

Klik setiap kotak alur untuk melihat interaksi antara peran Claude, pengguna, dan worker GitHub Actions.

Tahap 01 Eksplorasi Claude

Pencarian Kandidat & Verifikasi Judul Resmi

Claude mencari calon paper via web search dan mencocokkan judul serta penulis langsung ke halaman resmi abs arXiv sebelum diajukan ke antrian.

Aktor
Claude (web search & fetch)
Pemeriksaan Awal
Kesesuaian ID arXiv dan judul asli halaman abs
Keluaran
Objek JSON antrian siap commit
Tahap 02 Pemicu Pengguna

Penyusunan dan Commit queue/requests.json

Pengguna memasukkan daftar paper yang disiapkan Claude ke berkas queue/requests.json lalu melakukan commit dan push ke branch main.

Aktor
Pengguna (GitHub web atau git CLI)
Target Berkas
queue/requests.json
Efek Samping
Workflow GitHub Actions langsung terpicu otomatis
Tahap 03 Otomasi Runner

Pengunduhan dan 4 Tahap Validasi Worker

Runner GitHub Actions menjalankan scripts/queue_worker.py untuk mengunduh PDF dari arxiv.org, menguji 4 syarat fisik, dan mengekstrak teks ke Markdown.

Syarat 1 & 2
Header %PDF asli dan ukuran berkas > 30 KB
Syarat 3 & 4
Teks terbaca > 2.000 karakter dan kesesuaian judul >= 60%
Pembersihan
PDF biner dihapus dari repositori git, hanya simpan .md
Tahap 04 Verifikasi Claude

Pengambilan Data Berbasis Commit SHA

Claude memeriksa commit SHA terbaru dari repositori publik via GitHub API, kemudian membaca berkas ledger dan Markdown secara langsung tanpa cache.

Pencegahan Cache
Akses raw melalui jalur URL <sha> bukan <main>
Berkas Verifikasi
data/ledger.json dan data/markdown/<id>.md
Integritas
Pencocokan hash sha256 dan jumlah halaman
Tahap 05 Hasil Akhir

Rekonsiliasi Status dan Sintesis Terverifikasi

Claude menyusun sintesis ilmiah hanya dari paper berstatus valid dengan mencantumkan kutipan nomor halaman asli (## Page N) serta melaporkan paper gagal.

Sumber Kebenaran
Hanya dokumen valid di dalam buku besar ledger
Keamanan Konten
Teks diperlakukan sebagai DATA mentah (untrusted)
Format Sitasi
Penulis, tahun, nomor halaman, dan BibTeX tervalidasi

Matriks Rekonsiliasi Status Claude vs Git

Pedoman keputusan Claude saat memeriksa entri pada data/ledger.json.

Status di Ledger Arti Operasional Respon dan Tindakan Claude
Tidak Ada Entri Belum diproses (antrian baru atau workflow sedang berjalan) Laporkan bahwa dokumen masih dalam antrian, minta pengguna memeriksa tab Actions di GitHub.
valid Lolos 4 tahap pengujian fisik dan judul cocok Ambil teks Markdown via URL SHA commit, periksa kesesuaian judul, dan sintesis temuan ke laporan.
failed Gagal unduh atau tidak memenuhi kriteria validasi Laporkan alasan kegagalan secara transparan sesuai field reason, dilarang mereka-reka isi dokumen.
failed (3x) Batas maksimal percobaan ulang tercapai Minta perbaikan data masukan judul/ID atau sarankan paper alternatif.

Cara Pasang Paket Skill di Claude.ai

Pasang arsip skill ZIP ke Claude.ai tanpa perlu konfigurasi server tambahan:

  1. Unduh berkas rilis resmi: vpr-claude-skill.zip (versi 2.0.0).
  2. Buka Claude.ai di browser, klik menu profil, lalu buka Settings / Customize → Skills.
  3. Klik tombol Upload Skill dan pilih berkas vpr-claude-skill.zip.
  4. Saat memulai obrolan, beri tahu Claude alamat repositori publik Anda untuk pemrosesan antrian.

Pilihan lanjutan untuk developer yang ingin menjalankan worker lokal: periksa direktori scripts/ dan berkas workflow .github/workflows/vpr-queue.yml.
